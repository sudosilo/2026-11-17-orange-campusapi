Campus API

Campus API is the backend for Campus. It stores the transcript, sources, and logged work.

It serves course lists and plays them in order, saves the end of video log with status, note, and project link, and builds the transcript with credits weighted toward building over watching. It also keeps the stumble mode tools from the earlier backend, such as search, tags, and clips. It has a health route.
